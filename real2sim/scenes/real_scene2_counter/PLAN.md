# real_scene2：茶水间吧台 建模说明

v1，依据两张手机照片（2026-10-23 加了左侧客区，另有三张照片，见「左侧客区」）：`reference/photo.jpg` 从右前方拍，`reference/photo2.jpg` 从左前方拍。两张照片联合拟合了相机位姿和尺寸，台面两端都能看到，所以台面长度已经有约束。尺度仍然只来自微波炉宽度的假设值，没有卷尺实测。场景变更时同步更新本文件。

## 文件

| 文件 | 作用 |
| --- | --- |
| `fit_photo.py` | 两张照片上手工标的角点和边线，联合反求两台相机的位姿、共享焦距和未测尺寸，写 `fit_photo.json` |
| `fit_lounge.py` | 左侧客区的三张照片：相机位姿、墙纸凹龛和圆桌，写 `fit_lounge.json`（见「左侧客区」） |
| `fit_island.py` | 过道里两座岛台的四张照片：相机位姿、岛台尺寸、饮水机凹槽，写 `fit_island.json`（见「岛台」） |
| `build_scene.py` | 读三个 `fit_*.json`，生成 `usd/`（`background.usda`、`counter.usda`、`lounge.usda`、`island.usda`、`lights.usda`、`scene.usda`、贴图）和 RoboDojo Room 入口 `real_scene2.usd` |
| `check_scene.py` | 离线检查，写 `check_report.json` |
| `preview.py` | numpy 光栅化预览（`preview/`）。`compare_photo.jpg` 用两台拟合相机分别渲染，和对应照片并排，`compare_lounge.jpg` 是客区三张，`compare_island.jpg` 是岛台四张，`plan.jpg` 是去掉天花板的俯视图；只核对几何和贴图，不代表 RTX 效果 |

运行（本机无 Isaac 也可）：

```bash
uv run --no-project --python 3.11 --with usd-core --with trimesh --with numpy --with shapely \
    --with opencv-python-headless --with scipy --with mapbox-earcut --with manifold3d \
    sh -c "python fit_photo.py && python fit_lounge.py && python fit_island.py && python build_scene.py \
           && python check_scene.py && python preview.py"
```

`build_scene.py` 会删掉 `usd/parts.json`，之后在仓库根目录跑 `python scripts/scenes/scene_parts.py real2sim/scenes/real_scene2_counter` 重新生成。

## 坐标系

与 real_scene1 一致：Z 向上，米制；原点在台面中心正下方的地面；+X 沿台面，+Y 从机器人一侧指向墙。台面前沿 y = −D/2 = −0.28，墙面 y = +0.28。`fit_photo.py` 内部把墙放在 y = 0.30，`build_scene.py` 读入时平移。

## 左侧客区（2026-10-23，移动操作用）

吧台左木柱左边是一处客区：墙纸凹龛（下木护墙板、中间热带植物墙纸、上面背光的绿色竖条灯带、木吊顶），凹龛左端是另一根木柱，前面摆着两张圆桌。依据三张手机照片 `reference/lounge{1,2,3}.jpg`，`fit_lounge.py` 单独拟合三台相机和凹龛、圆桌（31 个像素约束，误差多在 1–5 px，最大 12.7 px），结果写 `fit_lounge.json`。尺度只来自“圆桌桌面高 0.75 m”这一个假设；三台相机拟合出的高度是 1.6–1.8 m，和手持拍照吻合。`preview/compare_lounge.jpg` 是三张照片和按拟合相机渲染的并排图。

## 需要实测的尺寸（卷尺 10 分钟）

1. 台面长（左木柱到右木柱）、进深、离地高度、前沿厚度。
2. 微波炉的外形尺寸，它是目前唯一的尺度基准。
3. 水槽开口长宽、深度，到台面左端和前沿的距离；水龙头底座位置。
4. 两层架子的离地高度、进深、右端位置。
5. 客区：圆桌高度和直径（目前唯一的尺度基准）、桌心到墙纸和到吧台左木柱的距离、吧台左木柱的宽度和凸出量、凹龛宽度、护墙板和墙纸的高度；椅子的宽、深、高、坐高和质量。
6. 岛台：两座台面的高度、长宽，靠墙边到吧台台面前沿的距离；吧凳座高和摆位（靠墙侧吧凳决定过道宽）；天花板高度和灯槽间距。

量到之后，整体比例不对就用 `build_scene.py --scale-correction` 缩放；单个尺寸不对，就在 `fit_photo.py` 里把对应先验的 sigma 调小，固定成实测值，重新拟合。

## 资产分层

- **`counter.usda` `/Counter`**：
  - 台面，带水槽开口和后挡水条；
  - 柜体，水槽上方挖空；
  - 5 扇无拉手柜门和台面下的凹槽，垃圾口门上有内嵌面板和标识贴花（从第二张照片裁出，用 alpha 镂空）；
  - 踢脚、水槽盆、沥水篮、水龙头、微波炉。

  碰撞体全部是静态盒体或凸包，purpose 为 guide。台面碰撞由水槽开口四周的 4 块盒体组成，开口不封闭；沥水篮占住水槽右半边。
- **`background.usda` `/Background`**：
  - 地面（水磨石）、大理石背板、木吊顶、左木柱；
  - 右侧木柜墙，带板缝、拉手槽和两格饮水机凹槽；
  - 左侧墙面和挂画、海报、插座；
  - 两层架子及架上物品（静态装饰，带简化碰撞）。
- **`island.usda` `/Island`**：高吧台（台面、铜立柱、铜鼓座）、绿色岛台（台面、铜踢脚、波纹板）、6 把吧凳、2 盏线形吊灯，以及它们的碰撞体（见「岛台」）。

## 接入 RoboDojo

1. 把本目录整体拷到服务器 `Assets/Room/real_scene2/`。`layout_manager.select_room` 会加载目录下唯一的 `.usd`，也就是 `real_scene2.usd`。
2. 在评测布局里去掉 `Table`、`Ground`、`Background`，换成：

```json
"Room": {"default": "real_scene2", "default_pos": [-0.35, -0.32, 0.0], "default_ori": [1, 0, 0, 0],
         "scale": [1, 1, 1], "collision": false, "table_height": 0.833}
```

   - `default_pos` 的 y = −0.32 把台面前沿放到 RoboDojo 默认桌沿 y = −0.60。
   - x = −0.35 让水槽和微波炉之间约 0.64 m 宽的空台面正对机器人，水槽在左边，微波炉在右边。
   - `table_height` 让 `relative_plane: "Table"` 的物体落在台面上。
3. **机器人站位。** 吧台是落地柜，G1-D 底盘不能像在无腿桌下那样伸进去。
   - `check_scene.py` 按站立圆柱 r = 0.22 m 估算，机器人根节点要从 y = −0.73 移到 y ≤ −0.80。这一项检查会一直 FAIL，用来提醒这件事。
   - 台面比办公室桌面（0.68 m）高 0.15 m，用升降柱补：`LZ_mt_Joint` 和 `LZ_it_Joint` 各 0.075。
   - 物体要整体平移 (0, −0.07, +0.15)，这样和机器人的相对位置与办公室场景一样，倒水脚本不用改。
4. 灯光放在 Room 里，多环境并行时会每个环境各有一套，和 real_scene1 是同一个问题。
