`evidence_scope.json` 列原文件 SHA 和未采纳原因。这里没有真机动作或相机采集脚本入口。

离线工具 `scripts/g1d/xense_gripper/calibration_fit.py` 支持 TCP 枢轴拟合、已检测滑移点的摩擦拟合、伺服轨迹误差/速度统计。输入必须带 `hardware_id`、`mount_id`，输出仍标为待独立留出验证。合成数据测试只验证计算和退化检查，不能变成真实标定结论。

要关闭实测项，仍需要当前装配的孔位/公差图、转接板及紧固件尺寸、安装与 TCP 测量；当前机器人和镜头设置对应的同步标定数据；部件质量/惯量、伺服和材料接触响应。遵守用户只做仿真的要求，本轮不补采真实数据。
