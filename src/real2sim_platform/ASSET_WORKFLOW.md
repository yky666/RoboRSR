# 实物资产登记与展示

新增物体依次完成：登记 → 字段核对 → 确认并生成统一 prompt → 建模与原生检查 → 对应范围入库。统一模板版本为 `real-object-v2`，实现位于 `object_registration.py`。v2（2026-10-28）新增「标签、贴纸与印刷图案」：实物标签必须从参考照片裁剪/展开成贴图，只贴在实物有标签的位置，缺照片要求补拍，并交付同视角照片对照图；v1 确认的记录需重新确认才会拿到新 prompt。

登记字段包含名称/类型/ID、实物与参考来源、材质、颜色、结构、建模要求、物理类型及测试要求。尺寸和质量分别选择实测、保留现有值、允许估计或待测。未知材质可明确写“待核实”；允许缺实测数据，但需确认如何处理缺项。历史已入库模型保留现有参数。

确认后，平台在 `spec.json` 记录确认人、模板版本和输入摘要，并导出同目录 `modeling_prompt.md`。字段、模型默认值或参考照片内容变化会使确认失效；编辑后需重新确认，不能继续调用旧 prompt。未确认记录只作为草稿，不能生成正式建模任务。统一 prompt 包含输入、几何外观、标签贴图、物理复用、验证和交付格式；模型生成与GPU验证由建模流程执行，点击确认本身不代表模型已通过检查。

场景列表隐藏 `g1d_green_table`、`g1d_green_table_isaac` 两个调试预览。源文件和验证记录保留，重新扫描不会使它们重新出现在公开展示列表。

本体管理展示已有机器人配置及站位配置的可复用本体。独立 `aurora_lite`、`ur5_official` 和未配置站位的 `g1d_aurora_upper` 归入研究资产；模型与原始记录保留。以后补齐站位、控制、观测、场景加载/复位验证，再审阅展示分类，不能仅以模型文件存在或可独立驱动作为完整接入依据。已有带完整配置的G1-D极光Lite版本不受影响。


实物来源与实测/验收独立：twin和asset_origin记录真实来源；尺寸/质量未实测也进入实物资产。photo_reference记录对话已收到的照片参考，reference/实际文件计入已归档；两类分开统计与展示，不以缺尺寸为由排除实物。
